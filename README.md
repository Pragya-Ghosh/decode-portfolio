# Decode 

A personal portfolio and technical blog built to showcase my projects, skills, and development journey. 

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, TypeScript)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Database**: [Supabase](https://supabase.com/) (PostgreSQL)
- **Content Rendering**: `react-markdown`, `@tailwindcss/typography`
